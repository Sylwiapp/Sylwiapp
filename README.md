# Sylwia's playground
I build small web products and tools for looking at psychophysiological signals.
## Hackathons
- [mamy wioskę](https://github.com/Sylwiapp/mamy-wioske) — a phone-first app for a local parent community. FastAPI, live on Render. Profiles show age band and distance, not a child's name or a home address.
- [Dziennik dwuboju](https://github.com/Sylwiapp/dziennik-dwuboju) — a pilot training log for Olympic weightlifting. A coach plans the week, an athlete logs it, and the app computes volume, tonnage, and ACWR.
- [Wartuś](https://github.com/Sylwiapp/BabyMonitor) — a toy baby monitor. FastAPI ingest over WebSocket and a PWA.
## Research
- [PsyPhy Datalab](https://github.com/Sylwiapp/psyphy_board) — a Streamlit dashboard for one session: respiration, EDA, ECG quality control, and a timed transcript.
Python, FastAPI, Streamlit, and plain browser apps.
